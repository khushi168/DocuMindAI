# DocuMind AI

AI-Powered Intelligent Document Processing & Workflow Automation Platform built using Python and FastAPI.

## Features

- Resume Parsing
- Offer Letter Analysis
- Invoice Data Extraction
- Meeting Notes → MOM Generator
- PDF Upload Support
- Text Input Support
- Dynamic Document Dashboards
- Rule-Based NLP Processing
- OCR Support (Local)

## Tech Stack

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SQLite
- OCR
- Regex-based NLP

## Supported Documents

- Resume
- Offer Letter
- Invoice
- Meeting Notes

## Run Locally

```bash
uvicorn app.main:app --reload
```
